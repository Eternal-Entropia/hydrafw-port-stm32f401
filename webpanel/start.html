DFU Firmware Flasher (WebUSB)

Flashing Steps:
1) Default: Firmare binary is automatically fetched directly from GitHub build/hydrafw.bin (or select a local file above);
2) Hold down the BOOT button on the BlackPill board (BOOT0 = 1);
3) Press and release RESET, then release BOOT — board enters STM32 DFU bootloader (VID 0x0483);
4) Click "Flash via DFU" and select STM32 BOOTLOADER in the browser popup.
After flashing: press RESET on the board. Flash address: 0x08000000.

Connecting to Web Panel

1. Connect the board via USB cable (USB-C).
2. Click "Enter Web Control Panel" (top button).
3. In the panel, click "Connect" and select your device.
4. Transport: Web Serial (automatic), fallback — WebUSB. Supported browsers: Google Chrome / Microsoft Edge (Chromium).
